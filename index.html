Kolki

Una aplicación Android moderna para el control de gastos personales con reconocimiento de voz offline.

Descargar App

🚀 Características Principales

📱 Funcionalidades Core

  • Registro rápido por voz: Doble toque en botones de volumen.
  • Registro manual: Formulario intuitivo con categorías.
  • Base de datos local: Almacenamiento offline con SQLite/Room.
  • Navegación por pestañas: Gastos, Estadísticas y Perfiles.

🎤 Reconocimiento de Voz

  • Offline: Usa la librería Vosk para funcionar sin internet.
  • Formato natural: "Comida, 25, almuerzo en la universidad".
  • Categorías inteligentes: Reconoce categorías comunes.
  • Números en español: Convierte "veinticinco" a 25.

📊 Estadísticas y Visualización

  • Totales por período: Semanal, mensual, anual.
  • Gastos por categoría: Con barras de progreso.
  • Gastos recientes: Lista de últimos movimientos.
  • Filtros y búsqueda: Para encontrar gastos específicos.

🏗️ Arquitectura Técnica

🛠️ Stack Tecnológico

  • Lenguaje: Kotlin
  • UI: Material Design 3 + View Binding
  • Base de datos: Room (SQLite)
  • Arquitectura: MVVM + Repository Pattern
  • Navegación: Navigation Component
  • Reconocimiento de voz: Vosk Android
  • Concurrencia: Kotlin Coroutines

🎯 Uso de la Aplicación

📝 Registro Manual

Abre la app, completa el formulario (categoría, monto, comentario) y guarda.

🎤 Registro por Voz

Presiona el botón "Por Voz" o haz doble toque en los botones de volumen y dicta el gasto.

📊 Ver Estadísticas

Analiza tus gastos totales, por período y por categoría en la pestaña de estadísticas.

⚙️ Configuración

Activa/desactiva el reconocimiento de voz, cambia la moneda y exporta o limpia tus datos.

🔧 Configuración de Desarrollo

📋 Requisitos

  • Android Studio Arctic Fox o superior
  • SDK mínimo: API 26 (Android 8.0)
  • SDK objetivo: API 36 (Android 15)
  • Kotlin 2.0.21

🚀 Instalación

1. Clonar el repositorio.

2. Abrir en Android Studio.

3. Sincronizar el proyecto con Gradle.

4. Ejecutar en un dispositivo o emulador.

🐛 Solución de Problemas

  • Reconocimiento de Voz No Funciona: Verificar permisos de micrófono y descarga del modelo Vosk.
  • Base de Datos Corrupta: Usar la opción "Limpiar Datos" en el perfil o reinstalar la app.
  • Rendimiento Lento: Limpiar datos antiguos y verificar el espacio de almacenamiento.
